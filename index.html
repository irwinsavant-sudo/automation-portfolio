Accounting App for card spend

A client project for a US company. It pulls card transactions from Plaid, asks each cardholder to respond in Slack, tracks replies on a live dashboard, and pushes completed items to QuickBooks. I built and run the whole system. Client name withheld.

What broke, what I changed

  • SQLite would not persist on the host.The host's filesystem does not support SQLite file locking. Now the database downloads on boot and uploads on sync, with write-ahead-log checkpoints and checksums so unchanged files are not re-uploaded.
  • Transactions disappeared between steps.A misconfigured Merge node dropped them without an error. Corrected the Merge configuration.
  • Plaid rejected requests.The proxy forwarded fields Plaid does not accept (UNKNOWN_FIELDS). The proxy now stops forwarding them.
  • The Worker pointed at old workflows.Its workflow map held stale IDs for all six workflows. Replaced them with the current IDs.
  • Uptime checks hit a private URL.The monitor pinged the private host directly. It now checks a health endpoint on the Worker.
